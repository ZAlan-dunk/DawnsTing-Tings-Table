# 婷馔清欢 · Ting’s Table

> **人间有味，四时清欢。**

“婷馔清欢”是一款面向所有用户的菜谱与食材选菜应用，帮助用户查询烹饪配方，并根据已经购入或家中现有的食材发现可以制作的菜品。

## 品牌信息

```text
中文名称：婷馔清欢
英文名称：Ting’s Table
品牌短名：婷馔
宣传语：人间有味，四时清欢。
当前版本：v0.0.1 Beta（规划中）
首发平台：Android APK
```

“婷”传递雅致、温柔与从容；“馔”代表用心准备的菜肴；“清欢”表达平凡饮食中的温暖与喜悦。

## 首版核心功能

### 1. 配方表

- 浏览全部菜谱
- 查看食材、用量、制作步骤和烹饪信息
- 搜索、分类和筛选菜谱
- 后续支持用户添加与维护自己的菜谱

### 2. 通过食材选择菜单

- 勾选已经购入或现有的食材
- 查找可以直接制作的菜品
- 区分“可以制作”和“缺少少量食材”的菜品
- 显示缺少的食材，辅助补充采购

## 产品方向

- 面向所有公开用户，不设置个人委托或个人专属署名
- 首版优先制作 Android APK，暂不发布独立网页版
- 优先采用离线可用、数据本地保存的方式
- 后续可扩展收藏、自定义菜谱、采购清单和数据备份

## 当前阶段

项目正在确认 v0.0.1 Beta 的详细需求、技术方案、菜谱数据与视觉规范。
