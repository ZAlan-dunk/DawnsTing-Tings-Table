# 懒羊羊当大厨~

一款仅供个人使用的本地优先菜谱与菜篮工具，提供 Android APK 和可添加到 iPhone/iPad 主屏幕的 PWA。本项目为非商业测试版，不面向商业运营或生产环境。

## iPhone / iPad 版

- 当前 PWA 版本：**v0.6.8-Bata**
- 打开地址：[懒羊羊当大厨~ PWA](https://zalan-dunk.github.io/DawnsTing-Tings-Table/)
- 安装方法：用 Safari 打开上方地址，点击“分享” -> “添加到主屏幕” -> “添加”。
- 安装后以独立窗口运行，支持浅色/夜间皮肤、离线应用外壳、安全区域和浏览历史返回。
- 菜谱、收藏、菜篮、采购清单、使用习惯和皮肤默认保存在当前浏览器。iOS 可能清理网页存储，首页提供 JSON 导出与导入。
- 私有云菜谱集为可选功能。GitHub 令牌由用户在当前设备内填写，仅保存在该浏览器，不写入公开 Pages 文件。
- 这是 PWA 网页应用，不是原生 IPA；后台任务、系统集成和存储保留规则受 iOS/Safari 限制。

## 现有功能

### 菜谱

- 内置 15 道普通家常菜，并支持本地添加、编辑和删除自定义菜谱。
- 支持按菜名、食材、口味、菜系和烹饪方式搜索。
- 支持“全部菜谱、我的收藏、自定义”范围筛选。
- 新增家常融合、川菜、湘菜、粤菜、江浙菜、北方菜、西式和其他八个菜系选项。
- 按烹饪方式分为：主食、汤羹、炒菜、蒸菜、炖煮、凉拌、空气炸锅、煎烤、烘焙和其他。
- 范围、搜索、菜系和烹饪方式支持任意组合，所有已选条件同时生效。
- 菜系与做法切换只改变当前展示的选项，不会清除另一维度的选择。
- 菜谱列表使用稳定条目更新，筛选、搜索和收藏时保留页面结构与搜索焦点。
- 点击菜谱详情中的食材，可以查看包含该食材的相关菜谱。

### 我的菜篮

- 使用简化的冰箱分层布局，按肉禽、水鲜、蛋豆、时蔬、谷物、水果、调料和其他整理食材。
- 记录数量、单位、备注和本周购入状态。
- 支持“充足、不多、用完”三种余量状态。
- 支持查看全部、本周新购、余量不多和已经用完的食材。
- 点击菜篮中的食材，可直接查看相关菜谱。
- “充足”和“不多”的食材会参与可制作菜谱匹配，“用完”不会参与。
- 匹配结果区分“可以开做”和“接近可做”，缺少食材可以一键加入采购清单。

### 采购清单

- 手动添加，或从菜谱与匹配结果加入缺少食材。
- 同名食材自动去重并按加入顺序保存。
- 标记买到后，可以输入数量和单位并直接放入菜篮，也可以仅从清单移除。

### 特典菜谱

当前保留两个特典入口：

- **婷馔清欢**：人间有味，四时清欢。
- **楚天云岫 · 云峰特典**：收录 150 道来源菜谱，按收藏顺序显示封面并跳转原菜谱。

## 视觉与适配

- 保留暖米白、黛青、朱砂、旧金与青瓷绿配色。
- 减少重复纹样、渐变、胶囊标签、边框和多重阴影。
- 菜谱卡片改为单一分类色条与清晰信息层级。
- 页面进入、筛选结果、收藏和按压反馈使用 90～180ms 的克制动效；系统关闭动画时自动静态降级。
- 筛选、收藏、返回、新增和底部导航的触控区域不小于 48dp，次要文字颜色满足小字号对比度要求。
- 菜篮通过分层和分类色增强辨识度。
- 适配状态栏、刘海/挖孔、底部手势区、横屏与平板宽屏。

## 数据与隐私

- 仅供个人、非商业用途，当前版本属于功能测试版。
- 菜谱、菜篮和清单默认保存在当前设备本地；只有显式同步时，编号菜谱集和其中的自定义菜谱才会写入私有仓库。
- 无需注册或登录。
- 不包含账号、社区、社交、广告或商业模块。
- 云峰特典使用 `INTERNET` 权限按需加载来源封面；其他核心功能仍可离线使用。
- 卸载 Android App 或清理 iOS Safari/PWA 存储会清除对应本地数据；重要内容应先同步菜谱集或导出 JSON。

## 构建

准备 JDK 17 与 Android SDK 36：

```powershell
$env:ANDROID_HOME='你的 Android SDK 路径'
$env:ANDROID_SDK_ROOT=$env:ANDROID_HOME
$env:RECIPE_CLOUD_TOKEN='仅限私有备份仓库 Contents 读写的细粒度令牌'
.\gradlew.bat testDebugUnitTest lintDebug lintRelease assembleRelease
```

个人测试 APK 使用独立且持续保留的测试密钥签名。签名密钥、密码、云端令牌、构建缓存和 APK 不提交到源码仓库。
