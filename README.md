# 婷馔清欢 · Ting’s Table

> **人间有味，四时清欢。**

“婷馔清欢”是一款面向日常家庭烹饪的 Android 菜谱应用。它帮助用户浏览家常菜配方、管理个人菜谱，并根据已经购入或家中现有的食材，发现当前可以制作或仅缺少少量材料的菜品。

## 下载 Android 测试版

- 当前版本：**v0.1 测试版**
- 系统要求：Android 8.0（API 26）及以上
- 安装包：[前往 GitHub Releases 下载 v0.1 测试版](https://github.com/ZAlan-dunk/DawnsTing-Tings-Table/releases/tag/v0.1-beta)

> APK 由项目发布密钥签名。Android 首次安装来自浏览器或文件管理器的 APK 时，可能需要允许“安装未知应用”。

## 首版核心功能

### 1. 配方表

- 内置 15 道普通家常菜谱
- 按菜名或食材搜索
- 查看菜品分类、口味、难度、用时与人数
- 查看食材用量、制作步骤和烹饪小贴士
- 收藏常用菜谱
- 自定义添加菜谱
- 编辑或删除自定义菜谱

### 2. 按食材选菜

- 勾选已经购入或家中现有的食材
- 食材选择自动保存在手机本地
- 基础调味料默认视为已有
- 区分“可以制作”和“还差一点”的菜品
- 显示匹配百分比与缺少的食材
- 将缺少食材加入采购清单

### 3. 采购清单

- 汇总需要补购的食材
- 完成后逐项移除
- 支持一键清空

## 内置菜谱

西红柿炒鸡蛋、酸辣土豆丝、青椒肉丝、可乐鸡翅、麻婆豆腐、蒜蓉西兰花、宫保鸡丁、家常蛋炒饭、紫菜蛋花汤、香菇炒青菜、家常红烧茄子、清蒸鲈鱼、土豆炖牛肉、蚝油生菜、南瓜小米粥。

## 数据与隐私

- 不要求注册或登录
- 收藏、自定义菜谱、食材选择和采购清单均保存在设备本地
- v0.1 使用 Android `SharedPreferences` 持久化数据
- 应用不申请网络权限，不上传个人数据

> 卸载应用通常会清除本地数据。v0.1 尚未提供导入导出，请在卸载前留意自定义内容。

## 构建说明

准备 JDK 17 或以上版本以及 Android SDK 36，然后执行：

```powershell
.\gradlew.bat assembleDebug
```

正式发布包需要使用项目原发布密钥签名，以保证后续版本可以覆盖安装。密钥与密码不存放在公开仓库中。
