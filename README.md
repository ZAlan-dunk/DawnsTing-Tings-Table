# 婷馔清欢 · Ting’s Table

> **人间有味，四时清欢。**

“婷馔清欢”是一款只为个人日常使用而开发的 Android 离线菜谱工具。它围绕两件事展开：浏览和维护自己的家常菜配方，以及根据家中已有食材判断现在可以做什么。

本项目不包含账号、社区、社交或商业内容，不依赖服务器，也不申请网络权限。

## 下载 Android 测试版

- 当前版本：**v0.3 测试版**
- 系统要求：Android 8.0（API 26）及以上
- 安装包：[前往 GitHub Releases 下载 v0.3 测试版](https://github.com/ZAlan-dunk/DawnsTing-Tings-Table/releases/tag/v0.3-beta)

## 核心功能

### 1. 配方表

- 内置 15 道普通家常菜谱
- 按菜名或食材搜索，并显示结果数量
- 支持西红柿/番茄、土豆/马铃薯等常用食材同义词
- 查看分类、口味、难度、用时、人数、用量、步骤和小贴士
- 收藏常用菜谱
- 添加、编辑和删除本机自定义菜谱

### 2. 按食材选菜

- 勾选已经购入或家中现有的主要食材
- 已选食材自动保存在手机本地
- 常备调料不计入主要食材匹配比例
- 区分“可以制作”和“还差一点”
- “还差一点”仅显示至少匹配一半、且缺少不超过 3 种主要食材的菜品
- 支持常用食材同义词匹配
- 可将缺少食材加入采购清单

### 3. 采购清单

- 按加入顺序保存待购食材
- 同名食材自动去重
- 勾选后移除，并支持短时间撤销
- 清空全部项目前进行二次确认

## v0.3 视觉升级

- 修复内容与手机状态栏、刘海/挖孔区域重叠的问题
- 适配底部手势区、三键导航区和软键盘
- 优化手机横屏、平板及较宽窗口的内容宽度
- 底部导航增加图标、文字和明确的当前页状态
- 搜索增加清除按钮、结果数量、输入法搜索动作和空状态
- 收藏状态不再只依赖颜色表达
- 配方详情强化元信息、用量对齐和步骤编号
- 食材匹配排除 0% 和低相关结果，并优化排序
- 食材选择增加已选数量、可移除标签和清空确认
- 自定义菜谱表单区分主要食材与常备调料，并增加字段校验和未保存提醒
- 页面状态与表单草稿可在配置变化时恢复
- 从收藏或食材匹配进入详情后，可返回原入口

完整版本记录见 [CHANGELOG.md](CHANGELOG.md)。

## 数据与隐私

- 无需注册或登录
- 无账号体系、社区、社交和商业模块
- 应用不申请 `INTERNET` 网络权限
- 收藏、自定义菜谱、食材选择和采购清单均保存在当前设备
- 使用 Android `SharedPreferences` 与 JSON 持久化本地数据
- v0.3 兼容 v0.1/v0.2 的本地数据键和自定义菜谱格式

> 卸载应用通常会清除本地数据。当前版本尚未提供导入导出，请在卸载前留意自定义内容。

## 构建说明

准备 JDK 17 和 Android SDK 36，然后执行：

```powershell
$env:ANDROID_HOME='你的 Android SDK 路径'
$env:ANDROID_SDK_ROOT=$env:ANDROID_HOME
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

正式发布包必须沿用原发布密钥签名，才能覆盖安装旧版本。密钥、密码、APK、构建缓存和本地 SDK 配置不提交到公开仓库。
