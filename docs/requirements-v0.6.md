# 懒羊羊当大厨～ v0.6.0-Bata 需求与验收标准

## 范围与身份

- 版本：`versionCode 7` / `versionName 0.6.0-Bata`
- 包名与命名空间：`com.dawns.tingstable`
- Android 8.0 / API 26 及以上，目标 SDK 36。
- 完全离线，不增加 `INTERNET` 或其他运行时权限。
- 保留收藏、自定义菜谱、菜篮和采购清单的原有本地数据。

## 菜谱浏览

- 菜谱页常驻区域只保留结果摘要、搜索图标、筛选图标和新增图标。
- 搜索图标打开可关闭的底部搜索面板；清除、提交和输入法搜索动作结果一致。
- 筛选图标打开底部筛选面板，同时提供范围、菜系和烹饪方式，取消不修改当前状态。
- 搜索和筛选使用独立激活状态与无障碍描述。
- 无结果状态提供可见且可点击的修改入口。
- 从详情返回后恢复范围、搜索词、菜系和烹饪方式。

## 首页

- 翻菜谱、打开菜篮、现有食材匹配和特典使用四枚不同的语义矢量图标。
- Hero 使用原创抽象小羊厨师素材，不依赖第三方角色文件或网络图片。
- Hero 显示当前菜篮数量和可制作菜谱数量；有推荐时进入菜谱详情，否则进入菜篮。
- 所有主要入口触控区域不小于 48dp，装饰图不重复进入无障碍树。

## 动效与适配

- 底栏页面使用 190ms 左右的轻量定向过渡。
- 详情进入和返回使用 220ms 左右的正反向过渡。
- 底部面板使用 220ms 以内的淡入与短距离上移。
- 系统关闭动画时所有交互立即进入最终状态。
- 320dp 宽度、横屏、平板和 200% 字体缩放下，必要内容可以重排且操作仍可到达。

## 自动验收

- 浏览状态单元测试覆盖默认摘要、范围标签、组合摘要、筛选计数、搜索状态和旧行为兼容。
- `testDebugUnitTest`、`lintDebug`、`lintRelease`、`assembleDebug` 和 `assembleRelease` 应通过。
- APK 元数据应为包名 `com.dawns.tingstable`、`versionCode 7`、`versionName 0.6.0-Bata`，且不包含 `android.permission.INTERNET`。
- 发布 APK 的签名证书应与 v0.5 测试版一致。
