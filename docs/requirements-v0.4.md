# 懒羊羊当大厨～ v0.4 需求与验收标准

## 1. 版本

- 显示版本：v0.4 测试版
- `versionCode 5`
- `versionName 0.4-beta`
- 包名：`com.dawns.tingstable`
- 最低系统：Android 8.0 / API 26
- 发布形式：签名 APK 与 GitHub Pre-release

## 2. 导航与品牌

- 应用显示名称为“懒羊羊当大厨～”。
- 首页显示“漂亮勒女明星～”。
- 底部导航为：首页、菜谱、菜篮、特典、清单。
- 收藏位于菜谱页面范围筛选，不占用底部导航。

## 3. 菜篮

- 支持肉禽、水鲜、蛋豆、时蔬、谷物、水果、调料和其他八类。
- 每项食材可记录名称、数量、单位、备注、购入时间和余量状态。
- 余量状态为充足、不多和用完。
- 支持全部、本周新购、余量不多和已经用完筛选。
- 充足和不多参与菜谱匹配，用完不参与。
- 旧版已选食材首次启动时迁移进入菜篮，迁移不可重复执行。

## 4. 菜谱分类与联动

- 分类为主食、汤羹、炒菜、蒸菜、炖煮、凉拌、空气炸锅、煎烤、烘焙和其他。
- 搜索、范围和分类筛选同时生效。
- 自定义菜谱可选择分类。
- 内置旧菜谱根据名称、原分类和步骤自动映射。
- 点击菜篮食材或菜谱详情食材，可以查询包含该食材的菜谱。
- 匹配结果可将缺少食材加入采购清单。

## 5. 特典

- 提供“婷馔清欢”和“楚天云岫 · 峰岳特典”两个入口。
- v0.4 暂不加入具体特典菜谱，详情显示“尚待入席”。

## 6. 清单联动

- 采购项目标记买到后，可以仅移除，或输入数量与单位后放入菜篮。
- 放入菜篮时，同名食材执行补货并恢复为充足状态。

## 7. 视觉与适配

- 保留既有配色，移除复杂动态背景。
- 普通卡片只使用一个主要分类色，不堆叠纹样、渐变、胶囊与多重阴影。
- 顶栏避让状态栏、刘海和挖孔；底栏避让系统手势区。
- 平板和横屏限制内容最大宽度。

## 8. 自动验收

- Java 编译、JUnit、Android Lint、Debug APK 和签名 Release APK 均成功。
- APK 不包含 `INTERNET` 权限。
- APK 元数据显示 `versionCode 5`、`versionName 0.4-beta`、`minSdk 26`、`targetSdk 36`。
- Release APK 通过签名验证，并与旧版本使用相同证书。
