# v0.6.2 Web 视觉原型

这是下一轮 APK 视觉方向的独立原型，不会改变当前安装包。

打开 `index.html` 即可查看；页面内可切换首页/菜谱和淡色/黑夜皮肤。Hero 已改为用户提供的懒羊羊图片，使用项目内 2400×1350 处理版本，并针对淡色与黑夜皮肤分别降低饱和度和亮度。入口卡片、皮肤按钮和底部导航的边框、标题与选中态也做了轻度加深，页面仍不依赖网络图片、渐变背景或多色卡片，用来先确认“轻、少、静”的方向。

当前环境未执行屏幕截图或 GUI 自动化。视觉方向和图片使用已经确认，并已开始将资源、token 和布局回填 Android `v0.6.2-Bata`。
