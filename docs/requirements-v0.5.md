# 懒羊羊当大厨～ v0.5 需求与验收标准

## 1. 版本与范围

- 显示版本：v0.5 测试版
- `versionCode 6`
- `versionName 0.5-beta`
- 包名：`com.dawns.tingstable`
- 最低系统：Android 8.0 / API 26
- 目标系统：Android SDK 36
- 发布形式：沿用原签名的 APK 与 GitHub Pre-release
- 本版本只优化菜谱分类、筛选和交互，不重做菜篮、特典或采购清单业务。
- 应用保持完全离线，不增加 `INTERNET` 或其他权限。

## 2. 菜系与数据兼容

菜谱增加独立 `cuisine` 字段，既有 `category` 字段继续承载烹饪方式兼容信息。菜系固定为：

1. 家常融合
2. 川菜
3. 湘菜
4. 粤菜
5. 江浙菜
6. 北方菜
7. 西式
8. 其他

- 内置 15 道菜谱均显式标注菜系，不根据名称动态猜测。
- 自定义菜谱的新建和编辑表单允许从固定菜系列表中单选。
- v0.1～v0.4 自定义菜谱缺少或使用空菜系时归入“家常融合”。
- 非空但不属于固定集合的菜系归入“其他”。
- 覆盖安装后继续读取收藏、自定义菜谱、菜篮和采购清单。

## 3. 四维组合筛选

菜谱结果按以下条件进行逻辑 AND 组合：

```text
范围（全部菜谱 / 我的收藏 / 自定义）
AND 菜系
AND 烹饪方式
AND 搜索词
```

- 菜系和烹饪方式各自单选，“全部菜系”和“全部做法”表示该维度不限。
- “按菜系 / 按做法”只切换当前展示的选项，不能清除另一维度已选值。
- 搜索覆盖菜名、口味、菜系、归一化后的烹饪方式和食材同义词。
- 重置筛选只清除搜索词、菜系和烹饪方式，保留当前范围与分类维度。
- 结果保持仓库原有顺序；空结果显示明确说明和可见的重置入口。
- 配置变化后恢复当前页面、范围、搜索词、菜系、烹饪方式和分类维度。

## 4. 列表与交互

- 菜谱页由固定筛选头和占满剩余空间的 `RecyclerView` 组成。
- 列表使用稳定菜谱 ID 与 `DiffUtil` 更新新增、删除、移动和收藏状态。
- 搜索、范围和分类变化不重建搜索框，保留输入焦点与页面结构。
- 菜谱卡片展示菜名、菜系、烹饪方式、用时、难度和主要食材摘要。
- 收藏操作即时更新图形、文字与无障碍描述；在“我的收藏”范围取消收藏时移除当前条目。
- 从详情返回菜谱页时恢复进入详情前的组合筛选状态。

## 5. 动效规范

| 场景 | 表现 | 时长 |
| --- | --- | --- |
| 页面进入 | 透明度 0→1，纵向位移 8dp→0 | 180ms |
| 筛选结果变化 | 轻量交叉淡化并配合列表差异动画 | 140ms |
| 收藏切换 | 0.86→1.08→1.0 缩放反馈 | 160ms |
| 普通按压 | 1.0→0.98→1.0 | 90ms |

- 动效不改变布局尺寸，不循环播放，也不阻塞点击。
- `ValueAnimator.areAnimatorsEnabled()` 为 false 时立即进入最终状态并执行更新回调。

## 6. 视觉与无障碍

- 继续使用暖米白、黛青、朱砂、旧金和青瓷绿，但不增加装饰性渐变、纹样或多重阴影。
- 次要文字色为 `#5D655F`，旧金色为 `#806126`，朱砂色为 `#98493D`。
- 三种颜色在 `#F6EFE4` 纸色背景上的对比度分别为 5.26:1、5.03:1 和 5.48:1，满足小字号 4.5:1 要求。
- 筛选、收藏、返回、新增、输入框和底部导航的最小触控高度为 48dp。
- 范围、分类维度和分类选项通过可见文字、填充状态、字重和动态内容描述共同表达选中状态。
- 收藏入口动态提供“收藏 / 取消收藏”内容描述；结果数量和筛选摘要提供可读文本。

## 7. 自动验收

- JUnit 覆盖菜系归一化、旧数据回退、固定菜系顺序、范围/搜索/菜系/做法组合和浏览状态重置。
- `testDebugUnitTest`、`lintDebug`、`assembleDebug` 和 `assembleRelease` 全部成功，Lint 为 0 项。
- APK 元数据显示 `versionCode 6`、`versionName 0.5-beta`、`minSdk 26` 和 `targetSdk 36`。
- APK 清单不包含 `android.permission.INTERNET`。
- v0.5 APK 与 v0.4 发布 APK 的签名证书 SHA-256 完全一致。
- 创建新 Tag `v0.5-beta` 和新的 GitHub Pre-release，附件包含 APK 与 `SHA256.txt`。
- v0.1～v0.4 的 Tag、Release、说明和附件保持不变。
