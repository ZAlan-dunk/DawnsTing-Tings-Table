# 懒羊羊当大厨 v0.5 菜系筛选与交互体验设计

## 1. 背景

v0.4 已提供菜谱搜索、收藏/自定义范围筛选和十种烹饪方式筛选，但 `Recipe.category` 同时承载旧分类文本与烹饪方式映射，缺少独立菜系维度。菜谱页每次切换分类或收藏都会重建整个页面，导致搜索焦点、滚动位置和视觉连续性变差。全局只有统一的页面淡入上移动效，收藏、筛选结果变化和状态切换缺少有意义的局部反馈。

本设计将菜谱主链路升级为“范围 + 菜系 + 烹饪方式 + 搜索”的组合筛选，并用克制、可降级的动效解释状态变化。应用继续保持完全离线，不改变既有账号、权限和本地优先原则。

## 2. 研究依据

- Material Design 3 的 Filter Chip 用于筛选内容；本项目用选择态明确的分类按钮承载单选菜系与做法，而不把命令动作伪装成筛选项：<https://m3.material.io/components/chips/guidelines>
- Material Motion 要求动效帮助界面表达并易于使用；Android 动画文档强调在内容或操作状态变化时提供视觉线索：<https://m3.material.io/styles/motion/overview>、<https://developer.android.google.cn/develop/ui/views/animations/overview?hl=en>
- NN/g 建议为动效定义目标、发生频率和力学表现，避免高频运动抢夺注意力：<https://www.nngroup.com/articles/animation-usability/>
- NN/g 对分面筛选的建议是仅保留用户真正需要的独立维度，因为更多维度会增加理解和维护成本。本版本只增加菜系，不扩张到食材、营养、场景等更多分面：<https://www.nngroup.com/articles/filters-vs-facets/>
- Android 建议可交互热区至少为 48dp，并要求小于 18sp 的普通文字达到至少 4.5:1 对比度：<https://developer.android.google.cn/guide/topics/ui/accessibility/apps?hl=en>
- WCAG 2.2 说明过小或过密的点击目标会增加误触；本项目采用更严格的 Android 48dp 建议：<https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html>

## 3. 目标与非目标

### 3.1 目标

1. 保留现有烹饪方式筛选，新增独立菜系筛选，并允许四类条件组合生效。
2. 旧收藏、自定义菜谱、菜篮和采购清单无损读取；旧自定义菜谱自动使用“家常融合”。
3. 筛选、搜索和收藏操作不再重建菜谱页面，保留搜索焦点与列表位置。
4. 为页面进入、筛选结果、收藏和按压提供有目的的短动效，系统关闭动画时静态降级。
5. 修正当前小字号金色、朱砂色和次级文字对比度不足，以及部分筛选按钮不足 48dp 的问题。
6. 发布可覆盖旧版本的 v0.5 测试版，并保留 v0.1-v0.4 所有 Release、Tag 和附件。

### 3.2 非目标

- 不重写为 Jetpack Compose，不全面迁移 Material 3 主题。
- 不重做菜篮、特典和采购清单的信息架构。
- 不加入账号、社区、广告、电商、云同步或 `INTERNET` 权限。
- 不增加营养、难度、用餐时段等额外筛选维度。
- 不加入循环背景、粒子、视差或纯装饰动效。

## 4. 数据与兼容设计

### 4.1 菜系字段

`Recipe` 新增 `String cuisine`。持久化 JSON 新增 `cuisine` 键；读取旧 JSON 时，空值和缺失值统一归一化为“家常融合”，非空但不在固定集合中的值归入“其他”。现有 `category` 键继续保留，语义固定为原始分类/烹饪方式兼容字段，避免破坏 v0.1-v0.4 数据。

菜系固定顺序为：

1. 全部菜系
2. 家常融合
3. 川菜
4. 湘菜
5. 粤菜
6. 江浙菜
7. 北方菜
8. 西式
9. 其他

自定义表单展示全部可编辑菜系。内置 15 道菜采用显式标注，不使用名称关键词自动猜测，避免同一道家常菜因地域争议产生不稳定分类。

### 4.2 内置菜谱标注

| 菜谱 | 菜系 |
| --- | --- |
| 西红柿炒鸡蛋、可乐鸡翅、蒜蓉西兰花、家常蛋炒饭、紫菜蛋花汤、香菇炒青菜、家常红烧茄子 | 家常融合 |
| 酸辣土豆丝、青椒肉丝、麻婆豆腐、宫保鸡丁 | 川菜 |
| 清蒸鲈鱼、蚝油生菜 | 粤菜 |
| 土豆炖牛肉、南瓜小米粥 | 北方菜 |

未被内置菜谱使用的菜系仍可由自定义菜谱选择，后续内容增加时无需迁移枚举。

### 4.3 组合筛选

新增纯 Java `RecipeFilters`，输入菜谱列表、收藏 ID、查询词、范围、菜系和烹饪方式，输出保持仓库原排序的结果列表。所有条件按逻辑 AND 组合：

```text
范围匹配
AND 菜系匹配
AND 烹饪方式匹配
AND 搜索匹配
```

搜索覆盖菜名、口味、菜系、归一化后的烹饪方式与食材同义词。空值等价于“全部”或空查询，不抛异常。

## 5. 菜谱页信息架构

菜谱页从上到下分为五个稳定区域：

1. **搜索与新建**：搜索框占主要宽度，自定义菜谱使用明确的新增按钮。
2. **范围分段控件**：全部菜谱、我的收藏、自定义三项互斥，选中态同时使用填充色与字重，不只依赖颜色。
3. **分类维度切换**：按菜系、按做法两项互斥，只决定当前展示哪组选项，不清空另一维度已经选择的值。
4. **分类选项与摘要**：当前维度横向展示单选项；摘要明确显示两个生效条件，如“川菜 · 炒菜”，并提供仅在存在筛选时显示的“重置”。
5. **结果列表**：显示结果数量、空状态和可滚动卡片列表。菜谱卡同时显示菜系、烹饪方式、时间与难度，避免用户必须进入详情才能判断分类。

菜系和做法各自只能选择一个值；范围、菜系、做法与搜索可组合。重置只清除搜索、菜系和做法，范围保留当前选择，避免用户在收藏页误跳回全部菜谱。

## 6. 列表与状态管理

菜谱列表改为 `RecyclerView`，使用稳定菜谱 ID 和 `DiffUtil` 计算新增、移除、移动与内容变化。页面外壳和筛选控件只在进入菜谱页时创建一次；筛选、输入和收藏只提交新列表。

- 收藏状态变化在“全部菜谱”中只更新当前卡片。
- 在“我的收藏”范围取消收藏时，卡片执行移除动画并保持其余位置稳定。
- 搜索输入不重建 `EditText`，因此不丢失光标和输入法状态。
- 菜系/做法切换保留两个选中值，返回当前维度时恢复选中样式。
- 旋转或进程恢复继续保存范围、菜系、做法、维度模式、查询词和当前页面。

## 7. 动效规范

新增统一 `MotionSpec`，所有时长集中管理并通过 `ValueAnimator.areAnimatorsEnabled()` 判断系统动画状态。

| 场景 | 方式 | 时长 | 目的 |
| --- | --- | --- | --- |
| 页面进入 | 透明度 0→1，Y 轴 8dp→0 | 180ms | 建立页面层级连续性 |
| 筛选结果变化 | 列表轻微交叉淡化 + DiffUtil 位移动画 | 140ms | 解释结果集合变化 |
| 收藏切换 | 星标 0.86→1.08→1.0 | 160ms | 确认操作已生效 |
| 普通按压 | Ripple + 0.98 缩放后恢复 | 90ms | 提供即时触控反馈 |
| 空状态出现 | 透明度 0→1 | 140ms | 避免内容突然跳变 |

系统关闭动画时，状态直接更新且最终布局与可访问描述一致。动效不得阻塞点击、改变布局尺寸、无限循环或用于纯装饰。

## 8. 视觉与无障碍

- 保留暖米白、黛青、朱砂、旧金和青瓷绿，但把小字号 `MUTED`、`GOLD`、`CINNABAR` 调深至在对应背景达到至少 4.5:1。
- 正文与控件文字最小 12sp；筛选项、收藏、返回、底栏导航和新增按钮的可点击区域至少 48dp。
- 收藏按钮继续提供“收藏/取消收藏”内容描述；菜系/做法维度、已选分类和结果数量均提供可读文本，不依赖颜色或位置表达。
- 卡片只保留单一烹饪方式色条；菜系作为文本元信息，不叠加第二套色块或胶囊，避免视觉噪声。
- 宽屏继续限制内容最大宽度；长菜系名称和按钮文字允许正常内边距与单行省略，不用随视口缩放字体。

## 9. 错误与边界处理

- 旧自定义 JSON 缺少 `cuisine`：归入家常融合并在下次保存时写入新键。
- 自定义菜系为空或未知：归入其他；表单仅允许固定选项，避免产生不可筛选值。
- 当前分类没有菜谱：展示包含当前筛选摘要的空状态，并提供重置按钮。
- 收藏目标在更新前已不存在：重新提交仓库当前列表，不崩溃。
- 动画被系统关闭：所有回调立即执行，界面不保持半透明或缩放状态。
