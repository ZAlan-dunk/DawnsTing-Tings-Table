# 懒羊羊当大厨~ v0.6.7-Bata 云端菜谱集

## 目标

- 将 v0.6.6 的整机备份/恢复入口替换为只同步菜谱的云端菜谱集。
- 普通菜谱集按 `Dew-0001`、`Dew-0002` 连续编号；已使用的编号不回退、不复用。
- 定制特典与普通菜谱集一起拉取到本机，但未输入密钥时不在界面显示。
- 密钥由 App 本机判断；不依赖 Cloudflare Worker、服务端令牌、管理恢复码或 Android Keystore 凭据。
- 保留现有“婷馔清欢”和“云峰特典”，本次新增的定制特典与它们相互独立。

## 云端状态

- App 使用仓库 Actions Secret 注入的 `RECIPE_CLOUD_TOKEN` 直连私有 GitHub 仓库。
- 共享状态保存于 `collections/state.json`，包含 `schemaVersion`、`nextNormalNumber`、`legacyMigratedProfiles` 和完整 `collections`。
- GitHub Contents API 的文件 SHA 用作乐观锁；409/422 后重新读取并重试。
- 普通菜谱集创建时从当前最大已用编号和 `nextNormalNumber` 的较大值继续分配。
- 非强制保存发现菜谱集 revision 已变化时返回 `VERSION_CONFLICT`；只有用户选择“保留本机”后才强制覆盖该菜谱集。
- 首次创建普通菜谱集时，可从对应 `backups/<profile>/latest.json` 迁移一次 `customRecipes`，不读取其他个人状态。

## 本机特典门禁

- 定制特典编号为 `KKLLTL`，默认名称为“露露的小厨房”，密钥随 App 打包并在客户端本地验证。
- 云端完整状态无论是否输入密钥都可下载和缓存。
- 未解锁时，定制特典不得出现在菜谱集列表、首页数量、页面恢复、活动菜谱集和按 ID 查找菜谱的结果中。
- 输入正确密钥后，本机持久保存“已解锁编号”，显示并允许改名、添加、编辑和删除其中的菜谱。
- 如果云端尚无 `KKLLTL`，正确密钥会触发创建空特典；如果网络不可用但本机已有缓存，则显示缓存。
- 输入错误密钥不得改变可见性。

## 菜谱集与浏览

- 首页提供“个人菜谱集”入口；菜谱集页先显示本机可见缓存，再刷新云端。
- 普通菜谱集均可创建、改名和编辑；所有使用者共享同一份 GitHub 状态。
- 同名菜谱通过 `custom-UUID` 保持独立，编辑时沿用原 UUID。
- 本机修改先保存并标记“待同步”；同步失败时不得删除本机内容。
- 搜索和筛选保持 48dp 小图标入口；分类模式按菜系分组并隐藏空分组。
- 习惯排序按本机历史打开次数降序，再按最近打开时间降序。
- 点击编号菜谱集后进入现有菜谱浏览页，继续支持搜索、筛选、分类和排序。

## 数据边界

- 只同步菜谱集编号、名称、类型、revision、时间与自定义菜谱。
- 皮肤、收藏、菜篮、采购清单、已选食材、浏览模式、点击次数和最近打开时间只保存在本机。
- Ting 与 Lulu 使用不同迁移 profile 和签名链，但共享云端菜谱集状态和同一套运行逻辑。

## 验收

- Given 两台设备同时创建普通菜谱集，when GitHub SHA 发生冲突，then 重读后获得不同且连续的新编号。
- Given 云端计数器落后于已存在的最高编号，when 创建普通菜谱集，then 从最高编号之后继续，不复用旧编号。
- Given 两道同名菜拥有不同 UUID，when 同步，then 两道菜均保留。
- Given 未输入特典密钥，when 拉取完整状态，then 普通菜谱集可见而 `KKLLTL` 及其菜谱不可见。
- Given 输入正确密钥，when 本机验证通过，then `KKLLTL` 可见、可进入、可改名和编辑。
- Given 通过配置恢复或菜谱 ID 查找隐藏内容，when 特典未解锁，then 必须回退到菜谱集页或普通菜谱结果。
- Given 本机与云端 revision 冲突，when 同步，then 显示明确选择且本机修改仍保留。
- Given 用户修改皮肤、收藏、菜篮或习惯排序，when 同步菜谱，then 这些字段不进入云端状态。
