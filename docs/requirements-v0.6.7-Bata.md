# 懒羊羊当大厨~ v0.6.7-Bata 云端菜谱集

## 目标

- 将 v0.6.6 的整机备份/恢复入口替换为只同步菜谱的云端菜谱集。
- 普通菜谱集由服务端连续分配 `Dew-0001`、`Dew-0002` 等编号；编号删除后不复用。
- 定制特典不出现在公开目录，输入正确密钥后才返回菜谱集内容和作用域访问令牌。
- 保留现有 APK 内置特典；本次不迁移“婷馔清欢”或“云峰特典”。

## 数据边界

- 云端保存：菜谱集编号、名称、类型、版本、时间和其中的自定义菜谱。
- 本机保存：皮肤、收藏、菜篮、采购清单、已选食材、浏览模式、习惯排序历史和访问令牌。
- 访问令牌使用 Android Keystore 加密；特典密钥不保存在设备或源码中。
- v0.6.6 历史备份原样保留；首次创建普通菜谱集时，服务端最多迁移一次对应 profile 的 `customRecipes`，不读取其他个人状态。

## 菜谱集

- 首页增加“个人菜谱集”，进入后先显示本机缓存，再刷新普通菜谱集公开目录。
- 没有可编辑菜谱集时，刷新完成后弹出普通菜谱集创建界面。
- 普通菜谱集可以公开读取，只有持有作用域令牌的设备可以改名或编辑菜谱。
- 创建时返回一次管理恢复码，卸载或换机后可恢复编辑权限。
- 定制特典的首条预留编号和默认名称由服务端环境变量配置；名称可以由授权设备修改。
- 本机修改先写入缓存并标记“待同步”。远端版本冲突时必须由使用者选择云端或本机版本，不静默覆盖。

## 菜谱浏览

- 搜索和筛选旁增加 48dp“分类模式”图标，可切换列表与菜系分组。
- 菜系分组隐藏空分组，并保持配置中的菜系顺序。
- 筛选面板增加“习惯排序”：按详情打开次数降序，再按最近打开时间降序。
- 打开次数和最近打开时间只保存在本机，不随菜谱同步。
- 点击编号菜谱集后进入现有菜谱浏览页，继续支持搜索、筛选、分类和排序。

## 验收

- Given 两台设备同时创建普通菜谱集，when 服务端提交成功，then 获得不同连续编号。
- Given 两道同名菜谱拥有不同 UUID，when 同步，then 两道菜均被保留。
- Given 普通目录请求，when 未提供特典令牌，then 响应中不包含定制特典编号、名称或内容。
- Given 本机修改与云端版本冲突，when 同步，then 显示明确选择且本机修改仍保留。
- Given 用户改变皮肤、收藏、菜篮或习惯排序，when 同步菜谱，then 请求体不包含这些数据。
- Given 200% 字号与窄屏，when 使用菜谱集、分类模式和排序，then 所有操作仍可达且主要列表不被永久筛选栏占据。

## 发布

- `versionCode 14` / `versionName 0.6.7-Bata`。
- 包名、显示名、Lulu/Ting profile、APK 基名和两个仓库各自签名链保持不变。
- 仅发布正式签名 APK，不构建、上传或交付 debug APK。
