# 懒羊羊当大厨～ v0.6.4-Bata 云峰特典

## 版本与边界

- `versionCode 11` / `versionName 0.6.4-Bata`。
- 包名与命名空间保持 `com.dawns.tingstable`，本地数据键与连续测试签名不变。
- 新增 `INTERNET` 权限，仅用于云峰特典加载来源封面；现有核心功能继续支持离线使用。
- 不增加账号、分析、广告、云同步或后台常驻服务。

## 内容目录

- “楚天云岫 · 峰岳特典”更名为“楚天云岫 · 云峰特典”。
- 从用户提供的公开收藏列表读取 10 页、150 道菜谱，按原收藏顺序保存目录。
- 每条目录仅包含唯一 ID、菜名、移动版原菜谱 URL 和封面 URL。
- 不复制第三方配方正文、作者信息或封面文件到源码、APK 或 Release。
- 提供可复现的结构化 HTML 导入器，CI 校验数量、唯一性和 URL 域名。

## 界面与交互

- 云峰特典入口显示 150 道收藏，详情页按三位序号排列。
- 首页与特典总览直接显示云峰特典的 150 道收藏状态，不再使用全为空席的提示。
- 手机使用单列卡片，600dp 及以上屏幕使用双列卡片。
- 封面区域尺寸稳定，远程图片成功后居中裁切；失败或离线时保留本地图标占位。
- 点击整张卡片通过系统浏览器打开 `m.xiachufang.com` 原菜谱。
- 仅允许 `https://i2.chuimg.com` 封面和规范的 `https://m.xiachufang.com/recipe/<id>/` 来源链接。
- 页面旋转或配置变化后仍恢复云峰特典详情。

## 性能与验收

- 封面最多使用 3 个并发线程、24MB 内存缓存、24MB 设备缓存、5MB 单图上限及连接/读取超时。
- RecyclerView 回收后不得把旧请求图片写入新卡片。
- 150 条目录、150 个唯一 ID、标题非空及域名约束通过本地与 CI 校验。
- 单元测试、Debug/Release Lint、Debug/Release 构建、APK 权限和连续签名校验通过。
- 旧 GitHub Releases 和安装包保持不变，新建 `v0.6.4-Bata` Pre-release。
