## 2. 核心功能一：配方表

### 2.1 菜谱数据

- 首版内置普通家常菜谱。
- 每道菜包含名称、分类、口味、难度、烹饪时间、建议人数、食材用量、步骤和小贴士。
- 用户可添加自己的菜谱。
- 自定义菜谱可编辑和删除，内置菜谱保持只读。

### 2.2 查询与详情

- 支持按菜名搜索。
- 支持通过食材名称搜索相关菜谱。
- 列表展示菜品摘要。
- 详情页展示完整食材用量和制作步骤。

### 2.3 收藏

- 内置菜谱和自定义菜谱均可收藏。
- 收藏结果自动保存在本地。
- 收藏页集中展示已收藏菜谱。

## 3. 核心功能二：按食材选菜

### 3.1 食材选择

- 用户从菜谱食材集合中勾选现有食材。
- 选择结果自动保存在设备本地。
- 基础调味料默认视为已有。

### 3.2 匹配规则

- 必需的非基础食材全部具备时，显示为“可以制作”。
- 缺少 1～3 种主要食材时，显示为“还差一点”。
- 结果显示匹配百分比和缺少的食材。
- 用户可从匹配结果直接打开菜谱详情。

## 4. 采购清单

- 可以把匹配结果中缺少的食材加入采购清单。
- 同名食材自动去重。
- 支持完成并移除单项。
- 支持清空全部采购项。
- 清单自动保存在手机本地。

## 5. 首页与导航

- 首页必须突出两个入口：
  1. 配方表。
  2. 按食材选菜。
- 底部导航提供首页、配方、选菜、收藏和清单。
- 手机竖屏为主要使用方式，交互区域适合触控操作。

## 6. 数据保存

- v0.1 仅使用本地保存，不需要账号。
- 使用 Android `SharedPreferences` 保存状态。
- 自定义菜谱使用 JSON 结构写入本地偏好设置。
- v0.1 暂不包含数据导入导出；该功能进入后续版本计划。

## 7. 平台与版本

- 平台：Android APK。
- 最低版本：Android 8.0 / API 26。
- 包名：`com.dawns.tingstable`。
- 显示版本：v0.1 测试版。
- 内部版本：`versionCode 1`，`versionName 0.1-beta`。

## 8. 公开仓库原则

- 产品品牌为“婷馔清欢 · Ting’s Table”。
- 仓库面向公开用户，不出现私人委托、个人专属或无关个人署名。
- APK 密钥、密码、构建缓存和安装包不提交到源码仓库。
- 安装包通过 GitHub Releases 分发。

## 9. v0.1 暂不包含

- 独立网页版本。
- 云端账号与同步。
- 菜谱图片上传。
- 数据导入导出。
- 营养与成本估算。
- 自动生成周菜单。
