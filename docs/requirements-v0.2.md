# 婷馔清欢 v0.2 优化需求与验收标准

## 1. 版本信息

- 显示版本：v0.2 测试版
- 内部版本：`versionCode 2`
- Android 版本名：`versionName 0.2-beta`
- 包名：`com.dawns.tingstable`
- 最低系统：Android 8.0 / API 26
- 目标系统：Android SDK 36
- 发布形式：签名 APK 与 GitHub Release

## 2. 范围原则

本版本只优化 v0.1 已有内容，不新增独立业务模块。

以下内容明确排除：

1. 账号、注册、登录和云同步。
2. 社区、评论、关注、分享动态和私信。
3. 广告、会员、付费、电商和其他商业功能。
4. 依赖联网服务的内容。
5. 独立网页版本。

## 3. P0：适配与阻塞问题

| 编号 | 需求 | 验收标准 |
|---|---|---|
| P0-1 | 状态栏与刘海适配 | 顶栏根据系统栏和挖孔安全区域增加边距，标题与系统图标不重叠 |
| P0-2 | 底部系统区域适配 | 底部导航与手势区、三键导航区不重叠 |
| P0-3 | 软键盘适配 | 自定义菜谱表单在键盘弹出时仍可滚动到当前字段和底部操作 |
| P0-4 | 宽屏适配 | 平板、横屏和较宽窗口使用居中最大内容宽度，避免卡片无限拉伸 |
| P0-5 | 数据兼容 | 覆盖安装 v0.1 后保留收藏、自定义菜谱、已有食材和采购清单 |

## 4. P1：核心流程优化

### 4.1 导航与首页

- 底部导航同时显示图标和文字。
- 当前页面具有文字颜色和背景形状双重状态。
- 每个导航入口具有无障碍内容描述。
- 首页明确说明个人、离线、无账号、无社区、无社交和无商业内容。
- 从收藏或食材匹配进入详情后，返回原入口。

### 4.2 配方搜索与详情

- 搜索支持菜名、食材和常用食材同义词。
- 显示搜索结果数量。
- 提供清除搜索按钮和输入法搜索动作。
- 无匹配结果时显示可理解的空状态。
- 收藏按钮同时显示图形和文字状态。
- 详情页清楚展示用时、人数、难度和口味。
- 食材名称和用量对齐展示，制作步骤编号化。

### 4.3 按食材选菜

- 显示已选食材数量和可单独移除的标签。
- 支持搜索食材和清空已选内容，清空前二次确认。
- 常备调料不计入主要食材匹配率。
- 0% 匹配结果不得出现。
- “还差一点”要求至少匹配一种、匹配率不低于 50%、缺少不超过 3 种主要食材。
- 结果显示已有数量、总数、匹配率和缺少食材。
- 结果按可制作、缺少数量、匹配率、用时和菜名排序。

### 4.4 采购清单

- 按加入顺序稳定保存。
- 同名食材去重。
- 勾选后立即移除，并允许在 4 秒内撤销。
- 连续操作时，旧撤销计时不得提前提交或关闭新提示。
- 清空全部项目前二次确认。

## 5. P2：表单与状态优化

- 自定义菜谱表单区分主要食材与常备调料。
- 新建菜谱必须包含菜名、至少一种主要食材、至少一步制作步骤、正整数用时和人数。
- 字段错误显示在对应输入框，并将焦点移到首个错误字段。
- 未保存离开时进行确认。
- 配置变化时恢复当前页面、搜索词、配方详情来源和表单草稿。
- v0.1 使用 `*` 标记常备调料的旧格式仍可解析。

## 6. 自动验证

- JUnit 覆盖 0 匹配排除、同义词、50% 阈值、常备调料和无主要食材等规则。
- Android Lint 不得有错误。
- Debug 与签名 Release APK 均应构建成功。
- Release APK 应通过 `apksigner` 验证。
- APK 元数据应显示 `versionCode 2`、`versionName 0.2-beta`、`minSdk 26` 和 `targetSdk 36`。
- v0.2 与 v0.1 的签名证书摘要应一致。

## 7. 人工验证建议

安装后建议在至少一台 Android 手机上检查：

1. 竖屏与横屏的顶栏、底栏和滚动区域。
2. 带刘海或挖孔设备的安全区域。
3. 系统字体调大后的标题、按钮和表单。
4. 搜索、收藏、食材选择、详情返回和采购撤销流程。
5. 从 v0.1 覆盖安装后的本地数据保留情况。

人工真机检查不替代自动构建、单元测试、Lint 和签名校验。
