# 婷馔清欢 · 产品方案

## 1. 产品定位

- 中文名称：婷馔清欢
- 英文名称：Ting’s Table
- 宣传语：人间有味，四时清欢。
- 产品类型：菜谱浏览、个人菜谱管理与按食材选菜的 Android 应用
- 目标用户：希望查询家常菜谱、利用现有食材安排菜单的普通用户
- 首发平台：Android APK
- 当前版本：v0.1 测试版
- 品牌气质：高雅、温和、清晰、实用

公开版本仅保留“婷馔清欢”这一产品品牌，不包含私人委托、个人专属或非必要的个人署名信息。

## 2. v0.1 产品目标

### 2.1 配方表

建立结构清晰的家常菜谱库。每道菜包含菜名、分类、口味、难度、用时、人数、食材用量、分步制作说明与小贴士。用户可以搜索、查看详情、收藏，并维护自己的自定义菜谱。

### 2.2 按食材选菜

用户勾选已经购入或家中现有的食材，应用计算菜谱匹配度，并将结果分为：

1. **可以制作**：主要食材已经齐全。
2. **还差一点**：缺少 1～3 种主要食材，可加入采购清单。
3. 其他低匹配菜品暂不作为首要推荐，避免结果过于杂乱。

油、盐、糖、生抽等基础调味料在 v0.1 中默认视为常备材料，不要求每次选择。

## 3. 已实现范围

1. 首页提供“配方表”和“按食材选菜”两个核心入口。
2. 底部导航包含首页、配方、选菜、收藏和清单。
3. 内置 15 道普通家常菜谱。
4. 支持按菜名和食材搜索。
5. 支持查看配方详情、用量、步骤、时间、难度、人数和小贴士。
6. 支持收藏菜谱。
7. 支持添加、编辑和删除自定义菜谱。
8. 支持选择已有食材并自动保存。
9. 支持显示匹配百分比和缺少食材。
10. 支持将缺少食材加入采购清单。
11. 支持采购清单逐项移除和一键清空。
12. 所有用户数据保存在手机本地，无需登录。

- 宫保鸡丁

- 香菇炒青菜
- 家常红烧茄子
- 清蒸鲈鱼
- 土豆炖牛肉
- 蚝油生菜
- 南瓜小米粥

## 5. 信息架构

- **首页**：品牌信息、版本、两大核心入口与功能概览。
- **配方**：搜索、菜谱列表、新建菜谱、详情、收藏、编辑和删除。
- **选菜**：选择已有食材、查看可制作菜品和接近匹配菜品。
- **收藏**：集中查看已收藏的内置或自定义菜谱。
- **清单**：查看、完成或清空需要采购的食材。

## 6. 技术方案

v0.1 已采用轻量原生 Android 方案：

- Java 原生 Android UI
- Android SDK 36，最低支持 Android 8.0 / API 26
- 单 Activity 页面状态切换
- `SharedPreferences` 保存收藏、自定义菜谱、已有食材和采购清单
- JSON 保存自定义菜谱结构
- Gradle 构建 APK
- 不依赖浏览器页面，不需要联网服务

选择这一方案的原因是首版范围明确、安装包轻量、离线可用，并且可以快速验证核心的菜谱管理和食材匹配体验。

## 7. 数据原则

- 本地优先：v0.1 不要求账号和服务器。
- 自动保存：修改收藏、食材、清单或自定义菜谱后立即保存。
- 隐私优先：应用不上传用户菜谱或采购数据。
- 升级稳定：后续版本应兼容 v0.1 的本地数据结构。
- 发布密钥稳定：后续 APK 必须沿用同一签名密钥，才能覆盖安装。

## 8. 视觉方向

采用现代东方食笺风格：

- 米白作为主要背景，降低长时间阅读疲劳。
- 黛青与青瓷色作为主色，突出清雅气质。
- 暖金作为少量强调色，用于关键操作和状态。
- 卡片保持足够留白，移动端点击区域清晰。
- 不依赖外部图片也能完整使用，便于离线分发。

## 10. 后续路线

优先考虑：

2. 增加更多家常菜谱和筛选条件。
