# 懒羊羊当大厨～ · 产品说明

## 产品定位

面向日常家庭烹饪的 Android 离线工具，重点解决两件事：整理可复用的家常菜谱，以及根据当前菜篮中的食材快速判断可以做什么。

## 核心原则

- 本地优先：收藏、自定义菜谱、菜篮和采购清单均保存在当前设备。
- 简单直接：不引入账号、社区、社交、广告、电商或其他商业模块。
- 核心闭环：菜谱、食材库存、匹配结果和采购清单相互联动。
- 可持续维护：内置家常菜作为基础，用户可以持续补充自己的菜谱。
- 视觉克制：暖米白、黛青、朱砂、旧金和青瓷绿构成主要色彩，不使用复杂动态背景。

## 当前版本

v0.4 测试版，Android 8.0 及以上，原生 Java 实现，完全离线运行。
