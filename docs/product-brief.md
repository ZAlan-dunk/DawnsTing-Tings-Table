# 婷馔清欢 · 产品方案

## 1. 产品定位

- 中文名称：婷馔清欢
- 英文名称：Ting’s Table
- 宣传语：人间有味，四时清欢。
- 产品类型：个人离线菜谱与按食材选菜的 Android 工具
- 使用对象：个人日常家庭烹饪
- 发布形式：Android APK
- 当前版本：v0.2 测试版
- 品牌气质：高雅、温和、清晰、实用

品牌只保留“婷”字形成的产品识别，不包含私人委托、真实姓名或非必要个人署名。

## 2. 固定产品边界

应用只解决个人设备上的菜谱查询、菜谱维护、食材匹配和采购记录问题。

明确不包含：

1. 账号、注册、登录和云端用户体系。
2. 社区、动态、评论、关注、私信或任何社交功能。
3. 广告、付费、会员、电商、推广或其他商业内容。
4. 依赖服务器的联网业务。
5. 与现有核心流程无关的大型扩展模块。

## 3. 核心流程

### 3.1 配方表

每道菜包含菜名、分类、口味、难度、用时、人数、主要食材、常备调料、分步制作说明和小贴士。用户可搜索、查看详情、收藏，并维护本机自定义菜谱。

### 3.2 按食材选菜

用户勾选已经购入或家中现有的主要食材，应用在本地计算菜谱匹配度：

1. **可以制作**：主要食材已经齐全。
2. **还差一点**：至少具备一半主要食材，且缺少不超过 3 种。
3. **不展示**：没有任何主要食材匹配，或匹配率低于 50%。

油、盐、糖、生抽等常备调料不计入主要食材匹配比例。

### 3.3 采购清单

将匹配结果中缺少的食材按加入顺序保存到本机清单，支持去重、逐项移除、撤销和清空确认。

## 4. 已实现范围

1. 首页突出“配方表”和“按食材选菜”两个核心入口。
2. 底部导航包含首页、配方、选菜、收藏和清单。
3. 内置 15 道普通家常菜谱。
4. 支持菜名、食材及常用食材同义词搜索。
5. 支持完整配方详情和结构化制作步骤。
6. 支持收藏菜谱。
7. 支持添加、编辑和删除本机自定义菜谱。
8. 支持选择已有食材并自动保存。
9. 支持匹配率、已有数量和缺少食材提示。
10. 支持采购清单。
11. 支持手机状态栏、刘海、导航区、软键盘、横屏和平板宽度适配。
12. 所有个人数据保存在当前设备，无需登录或联网。

## 5. 内置菜谱范围

西红柿炒鸡蛋、酸辣土豆丝、青椒肉丝、可乐鸡翅、麻婆豆腐、蒜蓉西兰花、宫保鸡丁、家常蛋炒饭、紫菜蛋花汤、香菇炒青菜、家常红烧茄子、清蒸鲈鱼、土豆炖牛肉、蚝油生菜、南瓜小米粥。

## 6. 信息架构

- **首页**：品牌、版本、个人离线定位和两个核心入口。
- **配方**：搜索、列表、新建、详情、收藏、编辑和删除。
- **选菜**：管理已有食材，查看可制作和接近匹配菜品。
- **收藏**：集中查看收藏的内置或自定义菜谱。
- **清单**：查看、完成、撤销或清空待购食材。

## 7. 技术方案

- Java 原生 Android UI
- Android SDK 36，最低支持 Android 8.0 / API 26
- 单 Activity 页面状态切换
- AndroidX Window Insets 处理系统栏、刘海和输入法区域
- `SharedPreferences` 保存收藏、食材、采购清单和数据版本
- JSON 保存自定义菜谱结构
- JUnit 验证纯本地食材匹配规则
- Gradle 构建和签名 APK
- Manifest 不声明网络权限

## 8. 数据原则

- 本地优先：数据只保存在当前设备。
- 自动保存：收藏、食材、清单和自定义菜谱操作立即持久化。
- 隐私优先：不上传菜谱、采购或使用数据。
- 升级稳定：v0.2 兼容 v0.1 的本地数据结构。
- 签名稳定：后续 APK 沿用同一发布密钥，以支持覆盖安装。

## 9. 视觉与交互原则

- 米白背景、黛青/青瓷主色和少量朱砂强调色。
- 关键信息不只依靠颜色表达，同时提供文字、图标或形状状态。
- 主要触控区域不小于约 48dp。
- 优先保证手机竖屏，同时兼顾横屏、平板和大字体。
- 系统状态栏、刘海、底部导航区和软键盘不遮挡主要内容。
- 搜索、空状态、错误提示、确认和撤销均给出明确反馈。
- 不依赖外部图片或在线资源也能完整使用。

## 10. v0.2 版本目标

v0.2 不增加新业务模块，集中修复适配、导航、搜索、匹配、清单和表单体验，并保持 v0.1 数据无损升级。
