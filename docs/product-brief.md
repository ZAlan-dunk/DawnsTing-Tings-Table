# 婷馔清欢 · 产品方案

## 1. 已确认信息

- 中文名称：婷馔清欢
- 英文名称：Ting’s Table
- 宣传语：人间有味，四时清欢。
- 产品类型：菜谱与食材选菜软件
- 目标用户：所有需要查询菜谱、利用现有食材安排菜单的用户
- 首发平台：Android APK
- 首版版本：v0.0.1 Beta
- 网页计划：首版暂不开发或发布独立网页版
- 品牌气质：高雅、温柔、诗意、清晰、实用

## 2. 核心产品目标

### 2.1 配方表

建立结构清晰、方便搜索与筛选的菜谱数据库。每道菜至少包含菜名、分类、食材、用量、步骤、耗时、难度和成品图片等信息。

### 2.2 通过购入食材选择菜单

用户勾选已经购入或家中现有的食材，应用根据食材匹配菜谱，并将结果分为：

1. 已有食材足够，可以制作。
2. 缺少少量食材，补充后可以制作。
3. 现有食材匹配度较低，作为备选推荐。

## 3. 首版建议范围

v0.0.1 Beta 优先完成：

1. 配方列表。
2. 配方搜索与分类。
3. 配方详情和制作步骤。
4. 食材勾选与管理。
5. 根据食材匹配可制作菜品。
6. 缺少食材提示。
7. 本地自动保存。
8. 基础设置与关于页面。

收藏、自定义菜谱、采购清单、营养估算和云同步等功能，由需求确认结果决定是否进入首版。

## 4. 技术方向

为了满足“首版直接提供 APK、暂不开发网页版”的要求，优先建议使用原生 Android 技术：

- Kotlin
- Jetpack Compose
- Material 3
- Room 本地数据库
- JSON 内置菜谱数据与备份
- Gradle 构建 APK

这种方案不依赖浏览器页面，可以获得更符合 Android 使用习惯的交互、返回键行为、权限管理和本地数据能力。

## 5. 视觉方向

采用现代化“东方食笺”风格：

- 主色：米白、黛青、青瓷绿
- 点缀：胭脂红或暖金
- 标题：具有宋体气质的中文字体
- 正文：清晰、易读的现代字体
- 元素：食笺、印章、四时花叶、餐具与食材线稿
- 原则：美术风格服务于阅读，不影响食材勾选和烹饪步骤操作

## 6. 发布方式

- GitHub 仓库公开源代码
- GitHub Releases 发布 APK
- README 提供最新版本下载入口
- 首版不启用 GitHub Pages 网页应用
