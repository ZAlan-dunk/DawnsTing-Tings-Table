# 懒羊羊当大厨~ · 产品说明

## 产品定位

面向日常家庭烹饪的 Android 本地优先工具，重点解决两件事：整理可复用的家常菜谱，以及根据当前菜篮中的食材快速判断可以做什么。

## 核心原则

- 本地优先：收藏、菜篮、采购清单、皮肤和使用习惯保存在当前设备；自定义菜谱可显式同步到编号菜谱集。
- 简单直接：仅供个人、非商业用途，不引入账号、社区、社交、广告、电商或其他商业模块。
- 核心闭环：菜谱、食材库存、匹配结果和采购清单相互联动。
- 可持续维护：内置家常菜作为基础，用户可以持续补充自己的菜谱。
- 视觉克制：默认使用低饱和浅色皮肤，并提供中性暗色的黑夜皮肤；不用复杂动态背景。

## 当前版本

`v0.6.7-Bata` 功能测试版，面向 Android 8.0 及以上，使用原生 Java 实现。菜谱、菜篮、匹配和采购清单均离线可用；云端只同步编号菜谱集与自定义菜谱，不同步个人设置或使用历史。菜谱浏览支持列表、菜系分类和本机习惯排序。本应用仅供个人使用，不面向商业运营或生产环境。系统返回键按页面层级导航，首页连续两次返回才会请求退出确认。
