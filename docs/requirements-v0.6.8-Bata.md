# 懒羊羊当大厨~ v0.6.8-Bata iOS PWA

## 目标

- 使用 GitHub Pages 提供 iPhone/iPad 可访问的 HTTPS 网页应用。
- 用户通过 Safari 的“添加到主屏幕”获得独立窗口、桌面图标和近似 App 的启动方式。
- 不创建 IPA，不改变 Android 包名、签名、版本号或现有 APK 发布。

## 功能范围

- 首页：紧凑文字 Hero、实时本机数据摘要、菜谱/菜篮/匹配/特典/个人菜谱集入口。
- 菜谱：15 道内置菜、个人菜、搜索、范围/菜系/做法筛选、菜系分类模式、习惯排序、收藏和详情。
- 菜篮：食材新增、编辑、删除、余量状态和可制作匹配。
- 采购：手动添加、缺少食材加入、买到后转入菜篮、移除和清空。
- 特典：保留婷馔清欢和云峰特典；云峰展示 150 道来源标题、封面和原链接。
- 菜谱集：顺序编号、同名 UUID 分离、`KKLLTL` 本地密钥门禁、离线待同步和显式云端刷新。

## iOS 安装与适配

- 提供有效 Manifest、180/192/512 PNG 图标、`apple-mobile-web-app-*` 元数据和 Service Worker。
- 使用 `env(safe-area-inset-*)` 适配刘海、圆角和底部手势区。
- 手机单列、平板双列；文字放大时工具栏折行，交互目标不小于 48px。
- 支持浅色/夜间皮肤和 `prefers-reduced-motion`。
- 详情、表单和二级页面进入浏览历史；主屏幕首页连续返回后显示退出确认。

## 数据

- PWA 本地数据与 Android 数据不自动互通。
- 浏览器本地保存菜谱、收藏、菜篮、采购清单、主题、使用习惯和云端缓存。
- JSON 导出/导入用于手动迁移与防止 iOS 清理网页存储后的数据丢失。
- 私有 GitHub 云同步为可选功能；用户令牌只保存在当前浏览器，不提交到仓库，不进入 Pages 构建物。

## 验收

- Manifest 和 Service Worker 引用的本地资源均存在并可从 Pages HTTPS 地址获取。
- 主页面、内置菜谱和云峰目录在首次成功加载后可离线重启。
- 普通菜谱集从云端最新状态分配 `Dew-xxxx`，冲突时重读后重试。
- 未解锁时隐藏 `KKLLTL`，正确密钥 `TL123` 仅在本机开启可见性。
- 同名菜谱使用不同 `custom-UUID` 时不会互相覆盖。
- 物理 iPhone 上的添加主屏幕、离线重启、方向切换、键盘、VoiceOver 和存储清理行为由实际设备最终确认。
